How to use multi user demo:

1. 	GitHub link for multiuser Fly Ash Demo portal
	https://bits2202.github.io/Fly-Ash-Auction/
2. 	Enter as auctioneer
3.	Set up the auction, wherein price bands and users may be added
4. 	Click on Push to bidders and copy the link and share with different users. 
5. 	Then bid with different users using names as prescribed viz. B1, B2, B3. 
6. 	Auctioneer can't bid and users/ bidders can't update the offered and cut=off qty. 
7. IMPORTANT: In case, any update is required in the multi-user demo, then upload the HTML file in Claude, download the updated file from Claude, open in notepad, copy the code and paste in the index file on GitHub.Replacing the original index file on GitHub is a bit tricky, so copy the code from Claude HTML file and paste it.
